All music, singing, sound effects, art and game designs are original. They are generated by this repository's
own code (`tools/songsmith`, procedural drawing in GDScript). Each day's design riffs on a theme from the games
listed in `game_list.txt`, and names it in game as "Inspired by …". No characters, assets, logos or music from
those games are used.
